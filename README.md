# Fit Log
### This side is useful to keep track your daily exercise. You can make plan for daily exercise and can save exercise for explore in future.

## Technology used
- NextJx
- TypeScript
- React
- Tailwind CSS
- React Toast
- HTML

## Key fetures
- Each exercise has instruction, duration, burned Calory
- Can make daily plan
- Can save for furure
- Duplicate selection is controled
- Can sort based on duration, rating and calories 
- Mark as done for complited exercise
- Delete exercise from your plan
